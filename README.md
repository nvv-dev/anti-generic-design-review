# anti-generic-design-review

> Que la interfaz no parezca hecha por IA: cada decisión, propia.

**Revisión anti-genérico** · Skill para agentes de código de la comunidad [nvvdev](https://github.com/nvv-dev). Funciona en Claude Code como plugin o como skill suelta, y en cualquier agente compatible con el formato abierto [`SKILL.md`](https://agentskills.io).

*English summary at the end.*

## Qué hace

Revisa un diseño, una maqueta o un PR de interfaz buscando los rasgos que delatan un diseño por defecto: degradados morados, tarjetas idénticas con íconos genéricos, títulos vacíos tipo "Transforma tu negocio", tipografía sin jerarquía, espaciado uniforme e ilustraciones de stock, entre otros. Por cada rasgo dice dónde está, por qué se ve genérico ahí y con qué decisión propia reemplazarlo, respetando los tokens y el contraste AA.

## Objetivo

Entregar interfaces que se reconozcan como de la marca y no como una plantilla más.

## Cuándo usarla

- Antes de entregar una dirección de arte, maquetas o una landing
- Al revisar un PR que cambia la interfaz

## Cuándo no

- Bugs o accesibilidad de fondo: usa code-review-deep y las pruebas de QA
- Discusiones de gusto sin dirección de arte aprobada: primero defínela

## Ejemplo

```text
Revisa la maqueta de la home con anti-generic-design-review antes de enviarla.
```

## Cómo se activa

Esta skill **se activa sola**: Claude Code lee su descripción y la carga cuando la tarea coincide. También puedes pedirla por nombre ("usa la skill anti-generic-design-review") o invocarla con `/anti-generic-design-review:anti-generic-design-review` (plugin) o `/anti-generic-design-review` (copiada a `.claude/skills/`).

## Instalación

### Opción 1: Claude Code, como plugin (recomendada)

Dentro de Claude Code:

```text
/plugin marketplace add nvv-dev/claude-plugins
/plugin install anti-generic-design-review@nvvdev
```

La primera línea agrega el catálogo de nvvdev una sola vez; la segunda instala esta skill. Si prefieres el paquete completo, instala `dev-workflow@nvvdev` en su lugar (incluye esta skill y las demás de [dev-workflow](https://github.com/nvv-dev/dev-workflow)); no instales los dos a la vez.

### Opción 2: Claude Code, copiando la skill

Para un solo proyecto (se comparte con tu equipo por git):

```bash
git clone --depth 1 https://github.com/nvv-dev/anti-generic-design-review.git /tmp/anti-generic-design-review
mkdir -p .claude/skills
cp -R /tmp/anti-generic-design-review/skills/anti-generic-design-review .claude/skills/
```

Para todos tus proyectos, cópiala en `~/.claude/skills/` en lugar de `.claude/skills/`.

### Opción 3: otros agentes

Copia la carpeta `skills/anti-generic-design-review/` en la carpeta de skills de tu agente (cada agente documenta la suya). Con la CLI [skills](https://github.com/vercel-labs/skills) de Vercel Labs:

```bash
DISABLE_TELEMETRY=1 npx skills add nvv-dev/anti-generic-design-review
```

### Verificar

Abre una sesión nueva y pregunta "¿qué skills tienes disponibles?"; `anti-generic-design-review` debe aparecer. Con el plugin, `/plugin` la muestra como instalada.

### Actualizar o desinstalar

- Plugin: `/plugin marketplace update nvvdev` para actualizar; `/plugin uninstall anti-generic-design-review@nvvdev` para quitarla.
- Copia manual: repite la copia para actualizar, o borra la carpeta `.claude/skills/anti-generic-design-review`.

Antes de instalar cualquier skill, incluida esta, conviene leerla: es un solo archivo, [`skills/anti-generic-design-review/SKILL.md`](skills/anti-generic-design-review/SKILL.md). Ver [vetting-external-skills](https://github.com/nvv-dev/vetting-external-skills).
